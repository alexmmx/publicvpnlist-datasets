PublicVPNList API developer kit

Public schemas, examples and validation tools for integrating with the technically checked PublicVPNList OpenVPN catalog.

Technical checks measure reachability and connection quality. They do not establish privacy, operator identity, ownership, logging policy, anonymity or trust.

curl --fail --show-error \
  'https://publicvpnlist.com/api/v1/servers?country=US&per_page=10'
